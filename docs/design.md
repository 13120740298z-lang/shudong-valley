# 《树洞谷》Shudong Valley — 设计底稿 v1

> 知乎黑客松 2026 校园新锐季 · 🧠 灵魂匹配局赛道
> 一句话：**一座可以真实住进去的像素小镇——你扮演一个角色在谷里自由行走，八位有记忆、有日程、会主动搭话的知乎居民生活在其中；你还能用一句话把一个新居民"写"进小镇。**

## 1. 玩法循环（每分钟都有事做）

1. **捏人入住**：选原型（考研人/搬砖人/漂着/换轨）+ 起名 + 选发色 → 降落谷口
2. **自由行走**：WASD/方向键/点地移动，四方向九帧动画，碰撞边界（有限开放：地图 44×34 tile，八区）
3. **撞见居民**：走近按 E/点击发起对话 → 星露谷式对话框，GLM 实时生成，**TA 记得你**（上次聊过"要不要考研"，下次见面会主动问进展）
4. **居民主动性**：
   - 你在附近驻足时，居民可能主动朝你搭话（头顶气泡）
   - 居民之间会互相聊天（广场/酒馆定时触发，全服可见）
   - 居民按日程移动：早上图书馆、中午广场、傍晚湖边（AI-Town 式日程，简化为时段锚点）
5. **一句话入住新居民**：在镇公所填写"一个总在减肥的火锅博主" → AI 生成人设卡（名字/口头禅/性格/日程/与既有居民的关系）→ 走出镇公所，TA 已经在镇上走动了 —— 全场唯一"玩家共创世界"设计
6. **知乎内容层**：
   - 公告栏 = 知乎热榜（API，缓存 1h）
   - 图书馆 = 知乎知识书架（免鉴权知识接口，可翻阅）
   - 灵感碎片：地上散落金句卡，捡拾进图鉴（收集进度=再来一次的动力）

## 2. 开放度与边界（像 MC 的自由，有墙的自由）

| 开放 | 边界 |
|---|---|
| 8 区域地图自由行走 | tile 碰撞+地图边界 |
| 与任何居民无限对话 | 单次对话 ≤40 回合防刷屏；对话频率 1 次/3s |
| 自定义居民 | 每位玩家上限 3 位，镇总上限 12 位；设定 ≤40 字；服务端人设审核词表 |
| 昼夜光照变化 | 固定 20 分钟一昼夜（演示压缩），不改玩法只改氛围 |

## 3. 架构（继续零依赖路线，一条命令跑起来）

```
web/
  index.html / app.js        SPA 壳 + 场景管理
  engine/   renderer.js      canvas 像素渲染（整数缩放、imageSmoothing 关）
            world.js          tile 地图数据 + 碰撞 + A 到 B 寻路（简化 BFS）
            player.js         输入、移动、朝向、动画帧
            npc.js            居民实体：日程状态机、行走、气泡
            dialog.js         星露谷式对话框 + 打字机 + 选项
            sprite.js         程序化像素画：tile/建筑/小人/物品（无外部素材）
  style.css
server/
  index.js                   静态 + API + SSE 广播
  services/llm.js            GLM(open.bigmodel.cn, OpenAI 兼容) ↔ mock 双模
  services/zhihu.js          热榜/知识/直答（env 门控，沿用官方文档实现）
  services/memory.js         居民记忆：对话摘要 + 对玩家印象，JSON 落盘
  world/  residents-data.js  8 居民人设（知乎内容锚定，原创撰写）
          map.js             地图 tile 矩阵与区域标注
  engines/ chat.js           对话编排：人设+记忆+场景→GLM→回复+记忆更新
          custom.js          一句话→人设卡生成
```

## 4. 美术：程序化像素（星露谷观感，零素材依赖）

- 全部精灵由代码逐像素绘制：16×16 tile（草/土路/水/花/树）、建筑为 tile 组合 + 门牌
- 角色精灵 16×20，四方向 × 3 帧走路循环，程序化换色（原型+发色）
- 配色：暖色像素调（草地 #7ABD4E 系、路 #D9A066 系、屋顶暖红/暖蓝），夜晚叠深蓝半透明层+窗户发光
- 对话框：米黄纸质感+像素描边+居民头像（精灵放大）
- 参考对象为公开的像素美学风格（星露谷/先祖人类细胞），**代码与美术全部原创实现，不使用、不复制任何第三方素材与代码**

## 6. GLM 接入

- 端点：`https://open.bigmodel.cn/api/paas/v4/chat/completions`（OpenAI 兼容，Bearer 鉴权）
- 模型：免费/低成本档优先（glm-4-flash 系），配置即用；未配 key 自动 mock（预生成台词池+规则合成），保证演示永不挂
- 记忆：每次对话结束由 GLM 产一条 ≤40 字印象（"玩家在纠结考研，倾向二战"），存 `memory/{npc}-{player}.json`，下次对话注入 system

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| GLM key 未配 | mock 双模（本次已验证该模式可靠） |
