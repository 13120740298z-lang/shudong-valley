| 光影 | 阴影是重点（作者视频原话） | 太阳方向光 + PCF 软阴影（2048 shadowmap）+ 贴地柔影 + 晨昏体积光柱（加色混合） |
| 昼夜 | 暖橙白天→深蓝夜晚+发光粒子 | 6 时段光照档（太阳色/强度/雾色/泛光）平滑插值；夜晚路灯点光池+窗光 |
| 水 | 波光粼粼、岸线泡沫 | 水面波光 mesh（加色流动纹理）+ 岸线泡沫绘制在水贴图 |
| 雨 | 斜雨+涟漪+雨雾（参考图夜景） | 3D 斜雨线段 900 滴 + 贴地涟漪环扩散 + 雨天雾距缩短；晴雨 40–90s 自动轮换，`?weather=rain` 强制 |
| 后处理 | Glow/朦胧感（作者用 Godot WorldEnvironment） | UnrealBloomPass 泛光，夜晚强度 0.8 |

## 二、工程落地进度（今天完成）

4. 昼夜光照（19:00 自动入夜：路灯亮起、画面转深蓝——截图确认）
5. 实时软阴影、贴地柔影
6. 3D 雨接入（`weatherState.raining=true` 状态确认）
7. 玩法层 100% 保留：NPC 日程/闲聊/记忆、对话、公告栏/图书馆/镇公所、灵感碎片
